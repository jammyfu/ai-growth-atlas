# AI Growth Atlas

> AI 專案依「漲星速度」排序，而不是總星數。

現有清單幾乎都按總星數排，老專案長期霸榜，新竄起的專案被淹沒。這裡替每個專案算出近 7 天 / 30 天 / 365 天的每日漲星數（星/天），依漲速排榜；總星榜放在最後。

資料取自 GitHub API，時間 2026-10-29 14:35:00（UTC）。

<details><summary>分類說明</summary>

| | |
|---|---|
| 編程助手 | 讓 AI 幫你寫程式、改程式、跑指令 |
| 技能與執行環境 | 替編程助手加技能包、記憶、稽核、安全 |
| 記憶與知識 | 讓 Agent 記住上下文、程式碼庫、文件 |
| 瀏覽器與電腦控制 | 讓 Agent 操作瀏覽器或桌面 |
| 文件與內容 | 把 PDF/PPT/影片等轉成可餵給 LLM 的格式 |
| 影片與媒體 | AI 生成或處理影片 |
| 安全與稽核 | 檢查程式碼或 Agent 行為的風險 |
| 本地模型與推論 | 在自己的機器上跑模型 |
| 工作流程自動化 | 把多個工具串成流程 |
| 其他 AI 工具 | 不屬於上面類別但正在漲的 AI 專案 |

</details>

## 數字怎麼來的

- 總星數：`GET /repos/{owner}/{repo}` 的 `stargazers_count`。
- 漲星數：`GET /repos/{owner}/{repo}/stargazers/history`（GitHub 提供、不含使用者身分的每週/每日星數）。取今天之前 N 個完整 UTC 日的總和（不含今天），星/天 = 漲星數 ÷ N。
- GitHub 說明週/日分桶邊界不保證與 UTC 對齊，且之後取消的 star 不計入，所以視窗邊緣可能有小幅誤差。
- 漲星曲線是 `star-history.com` 的 SVG 圖片，以 URL 引用。本儲存庫不含任何統計或追蹤腳本。
- 原始資料在 [`data/stats.json`](data/stats.json)；每日星數快照追加在 [`data/stars.json`](data/stars.json)。

## 貢獻

在 `data/projects.json` 加一筆（`desc` 需寫齊五種語言），然後執行 `python tools/update_stars.py`。每日更新見 [docs/DAILY_UPDATE.md](docs/DAILY_UPDATE.md)。
