GitHub 涨星榜（GitHub Risers）

按涨星速度（每天新增 star 数）而不是总 star 数，给 GitHub 热门仓库排名。AI 是主榜，开发工具、安全、前端、基础设施、设计、数据各有自己的榜。数字直接取自 GitHub API，每天更新两次。

它是脚本生成的榜单：不是 GitHub 官方产品，不是人工精选清单，也不是买星或推广服务。

常见问题

GitHub 涨星榜是什么？

一份按涨星速度而不是总 star 数排序的 GitHub 仓库榜单。AI 是主榜，开发工具、安全、前端、基础设施、设计、数据各有独立榜单。

涨星速度怎么算？

每日涨星 = 窗口内新增 star 数 ÷ 所用天数。新增数取自 GitHub API 的 stargazers/history，按运行日之前完整的 UTC 日累加。比窗口更新的仓库用自己的年龄做除数，并标为新仓库。

多久更新一次？

每天两次：北京时间 0 点（UTC+8）和美西洛杉矶时间 0 点。由 GitHub Actions 定时触发，可能晚几分钟开始。每次运行都会在仓库里单独存档。

它和 GitHub Trending 一样吗？

不一样。GitHub Trending 是 GitHub 自己的页面；涨星榜是独立的开源项目，规则公开，每次更新都有存档，与 GitHub 无任何关联。

“最热新仓库”榜怎么选？

近 7 天内创建、至少 100 star、非 fork、未归档的仓库，按 star 数 ÷ 仓库年龄（天）排序。

能识别刷星吗？

不能。它只如实报告 GitHub API 返回的数字。仅对疑似破解 / 盗版合集的新仓库用公开的规则标记，并排在所有正常仓库之后。

用了生成式 AI 吗？

榜单由普通脚本计算。新仓库描述的翻译可在一个可选步骤里用 AI 模型生成；数字从不由 AI 生成。

怎么引用？

使用仓库里的 CITATION.cff（GitHub 页面有“Cite this repository”按钮），并注明所用快照的日期。
