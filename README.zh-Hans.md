# AI Growth Atlas

> AI 项目按「涨星速度」排序，而不是总星数。

现有列表几乎都按总星排，老项目长期霸榜，新涨起来的项目被淹没。这里给每个项目算出近 7 天 / 30 天 / 365 天的每日涨星数（星/天），按涨速出榜；总星榜放在最后。

数据取自 GitHub API，时间 2026-10-29 14:35:00（UTC）。

<details><summary>分类说明</summary>

| | |
|---|---|
| 编程助手 | 让 AI 帮你写代码、改代码、跑命令 |
| 技能与运行时 | 给编程助手加技能包、记忆、审计、安全 |
| 记忆与知识 | 让 Agent 记住上下文、代码库、文档 |
| 浏览器与电脑控制 | 让 Agent 操作浏览器或桌面 |
| 文档与内容 | 把 PDF/PPT/视频等转成可给 LLM 用的格式 |
| 视频与媒体 | AI 生成或处理视频 |
| 安全与审计 | 检查代码或 Agent 行为的风险 |
| 本地模型与推理 | 在自己机器上跑模型 |
| 工作流自动化 | 把多个工具串成流程 |
| 其他 AI 工具 | 不属于上面类别但在涨的 AI 项目 |

</details>

## 数字怎么来的

- 总星数：`GET /repos/{owner}/{repo}` 的 `stargazers_count`。
- 涨星数：`GET /repos/{owner}/{repo}/stargazers/history`（GitHub 提供的不含用户身份的每周/每日星数）。取今天之前 N 个完整 UTC 日的总和（不含今天），星/天 = 涨星数 ÷ N。
- GitHub 说明周/日分桶边界不保证与 UTC 对齐，且后来取消的 star 不计入，所以窗口边缘可能有小幅误差。
- 涨星曲线是 `star-history.com` 的 SVG 图片，按 URL 引用。本仓库不含任何统计或追踪脚本。
- 原始数据在 [`data/stats.json`](data/stats.json)；每日星数快照追加在 [`data/stars.json`](data/stars.json)。

## 贡献

在 `data/projects.json` 里加一条（`desc` 需写全五种语言），然后运行 `python tools/update_stars.py`。每日更新见 [docs/DAILY_UPDATE.md](docs/DAILY_UPDATE.md)。
