# GitHub Risers: Trending Repos Ranked by Star Growth

> GitHub trending ranked by star growth, not total stars. AI first, plus developer tools, security, web, infrastructure, design and data. Refreshed twice a day, with a 7-day new-repo board in every category.

Total-star lists keep the old giants on top and bury what is taking off right now. GitHub Risers ranks repos by stars gained per day (last 7, 30 and 365 days) and groups them into categories, with AI as the main board. Every category has a hottest-new-repos board for repos created in the last 7 days, then week, month and year star-growth rankings, and total stars last. All numbers come straight from the GitHub API. Classification rules: [docs/CATEGORIES.md](docs/CATEGORIES.md).

Updated twice a day: 00:00 Beijing time (UTC+8) and 00:00 Los Angeles time (America/Los_Angeles, follows daylight saving). Each update is archived under its own time slot.
Each category ranking shows up to the top 20 of 70 tracked projects across all categories.

## How the numbers are produced

- Total stars: `GET /repos/{owner}/{repo}` → `stargazers_count`.
- Stars gained: `GET /repos/{owner}/{repo}/stargazers/history` (GitHub's privacy-safe weekly/daily star counts). The gain is the sum of the N complete UTC days before today (today is excluded). Stars/day = gain ÷ N.
- GitHub states that week/day bucket boundaries are not guaranteed to align with UTC, and stars that were later removed are not counted, so the figures can be off by a small amount at the window edges.
- Star history curves are `star-history.com` SVG images embedded by URL. This repo contains no analytics or tracking script of any kind.
- The raw numbers are in [`data/stats.json`](data/stats.json); daily snapshots of the star count are appended to [`data/stars.json`](data/stars.json).
